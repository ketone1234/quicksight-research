## 表記ルール

- 「要検証」: 公式情報で確かめきれなかった点。試用アカウントで確かめてから本番設計に入れる
- 「第三者情報」「コミュニティ情報」: AWS 公式以外が出典の点
- 画面の項目名は英語 UI の表記のまま書いた。日本語 UI の表記との対応は確かめていない
- `111122223333`、`<DATASET_ID>` などはダミー値。自分の環境の値に置き換える

## 転記のコツ

- `>` で始まる行や「注意」は、Confluence の「情報」または「注意」パネルにすると目立つ
- コードと JSON は「コードブロック」マクロに入れる（言語は json / bash / sql）
- 親ページに「子ページ一覧」マクロを置くと目次になる
- 長い JSON は転記の手間が大きい。最小例だけ写し、詳細は公式ページへリンクしてもよい
